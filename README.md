# Transaction Tracker Dashboard

This is a web-based transaction tracker I built to practice working with financial-style data and client-side state management. It lets users add transactions, categorize them, and see a running balance update in real time.

I wanted this project to feel like a simplified version of tools used to track spending or internal financial activity.

---

## Features

- Add income and expense transactions
- Assign categories like Food, Utilities, and Transport
- Filter transactions by category
- Live balance calculation
- Visual difference between income and expenses
- Data persists using localStorage
- Simple UI with small animations

---

## Built With

- HTML
- CSS
- JavaScript (vanilla)
- localStorage

---

## What I Learned

- How to manage application state in JavaScript
- Rendering dynamic table data based on user input
- Using localStorage to persist data across page refreshes
- Structuring code so it’s readable and easy to update
- Designing a UI that makes numeric data easier to read

---

## How to Run It

1. Clone the repo
2. Open `index.html` in your browser
3. Start adding transactions

No setup or dependencies needed.
